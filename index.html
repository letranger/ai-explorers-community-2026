3. 召集人任務

經費來源: 教育部人工智慧技術與應用人才培育計畫 社群名稱: 中小學AI探索者高中組南區社群 社群任務: 本年度5-11月間 辦理5次共學活動。共學活動主題以AI教學知能提升、跨域應用教學為主要共學方向。 社群成員福利：

  1. 提出大家感興趣之主題，由計畫經費聘請相關領域人員分享心得
  2. 社群成員彼此交流分討教學經驗
  3. 撰寫共學心得，稿費500元；入選作品2000元。

召集人於共學活動辦理期間需要協助的工作如下：

  1. 協助辦理AI共學活動：
    1. 預計於115年度辦理5次共學活動，形式可以實體、線上或混成（實體+線上）方式辦理，首次活動需為實體活動。計畫辦公室會提供各組完成AI Dreamer培訓的種子教師名單，由召集人協助通知名單內老師參與共學活動。
    2. 第一次建議以實體為主
    3. 共學活動辦理期間：115年5月1日到11月20日。
    4. 共學主題以 AI教學智能提升、跨域應用教學 為主，可以和組員討論。共學資源不限
    5. 共學類型：
      • AI教學智能提升
      • AI踦領域教學:AI融入各領域
      • AI輔助教學:工具應用介紹
  2. 參與期末交流大會： 計畫辦公室於年末(本年度12月或隔年1月)辦理交流會議，讓各組召集人能分享各組共學情形和共學資源。
  3. 撰寫年度目標： 計畫辦公室提供年度規劃表格式，由召集人協助填寫共學活動具體細節與經費使用規劃。
  4. 協助記錄活動、核銷與繳交相關資料：
    1. 整理共學活動資料(如：簽到表、照片、教材)和核銷單據，以及填寫「共學紀錄表」。
    2. 協助邀請參與共學的成員填寫「共學心得回饋表」（由辦公室提供線上表單連結），以及年度末協助彙整成員本年度參與共學活動心得。

計畫辦公室提供資源，下列經費項目與其他資源將於近期召開線上說明會時進一步說明：

  1. 召集人出席費：每次辦理共學活動支付召集人一次出席費。
  2. 交通費、膳費：辦理實體共學活動提供與會成員(含召集人)交通費用。
  3. 講座鐘點費：各組提供2次講座鐘點費，邀請講師進行專業增能。
  4. 實作材料費：辦理實體活動包含硬體實作需求，提供相關材料費用實支實付（採購前請先與計畫辦公室確認採購項目）。
